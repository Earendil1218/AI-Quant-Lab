# 技术决策记录

## 2026-08：Python 版本选择

### 决策

选择 Python 3.11 作为主要开发环境。

### 原因

- `ib_insync` 兼容性更好
- 金融量化生态成熟
- 稳定性优先

### 暂不使用

- Anaconda
- Docker
- 数据库系统
- 自动交易框架

### 原因

项目初期优先建立 Python 量化研究基础。

## 2026-08：TWS API 只读连接

### 决策

在量化研究与数据获取阶段，TWS API 连接统一使用只读模式。

### 原因

- 防止研究脚本意外提交订单
- 符合当前仅获取账户与市场数据的需求
- 避免只读 TWS 配置下的订单同步超时
