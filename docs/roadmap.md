# AI-Quant-Lab 路线图

## Phase 0：开发环境搭建

完成 Python、VS Code、Git、Codex 与基础项目结构的配置。

## Phase 1：IBKR 数据连接

建立并验证通过 IBKR TWS API 获取数据的能力。

## Phase 2：股票数据获取和处理

获取、清洗、存储并分析股票历史数据。

## Phase 3：期权定价模型

- Black-Scholes 模型
- Implied Volatility 计算
- Greeks 计算：
  - Delta
  - Gamma
  - Theta
  - Vega

## Phase 4：策略研究

- Covered Call
- Cash Secured Put
- Bull Call Spread
- Bear Put Spread
- Iron Condor
- Calendar Spread

## Phase 5：策略回测

- 历史数据回测
- 盈亏曲线
- Sharpe Ratio
- 最大回撤
- 胜率分析

## Phase 6：AI 辅助量化研究

- AI 分析市场
- 自动生成策略
- 自动回测
- 策略优化

## Phase 7：模拟交易和自动化交易

在模拟环境中验证策略执行流程，并研究自动化交易能力。
